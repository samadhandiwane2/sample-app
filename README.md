# Sample App

A sample Java application built with Maven and containerized with Docker.

## Prerequisites

- [Java JDK](https://adoptium.net/) (version 17 or higher recommended)
- [Maven](https://maven.apache.org/) (or use the included wrapper `./mvnw`)
- [Docker](https://www.docker.com/) (optional, for containerization)
